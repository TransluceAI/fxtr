# Implementation notes preamble (copy into each indivial plan file)
```
As you go, you should remind yourself to take short breaks between steps to re-orient and track your state:
- Check off each step immediately after finishing the step. Don't check it off before starting work, wait until after. But also remember to check it off before moving on to the next step.
- Then, right after finishing each step and checking it off, go to `plans/{name_of_this_file}_impl_notes.md`, and add an implementation notes section for this step describing anything weird you ran into, any ambiguous situations you had to make a judgement call about, any work left for later, or any things you ran into that you think deserve a closer look or deserve following up on. You can use `plans/impl_notes_template.md` as a template. The purpose of this file is to make sure important loose ends don't get lost. If you don't have any particular notable findings to write here, feel free to just comment briefly on your experience doing that step, and whether you felt like it went well or was tricky.
- Then look at the next step, make sure you understand what you need to do, and mark it as "in progress".
```
