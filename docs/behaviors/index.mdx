---
title: "What is the behaviors library?"
description: "Primitives for evaluating AI model behavior."
---

<Note>
  The behaviors library documentation is still under construction.
</Note>

**behaviors** is a Python library for building AI evaluations. It provides model adapters,
multi-turn conversations, user and tool policies, and structured conversation records.
Use it to sample a model, simulate an interaction, or ask a model to judge another model's
output.

You control the messages, tools, and stopping conditions of an interaction. behaviors handles
the conversation loop and provides configurable retries and failure recording. Users can be
scripted, or simulated by models: a base model writing the user's messages, optionally steered
by a chat model (see [Simulated users](/behaviors/guides/policies-and-tools#simulated-users)).
To have a model judge another model's output, `judge` asks a model to assess evidence against
a rubric and returns its answer, checked against a schema, with its citations (see
[Judging](/behaviors/reference/api#judging)). The
[judge step](/behaviors/guides/language-models#a-judge-step) shows `judge` grading a
conversation in an fxtr step.

behaviors works with [fxtr](/fxtr): conversation records can be stored as fxtr entities,
returned from steps, and inspected in the experiment viewer. fxtr manages the experiment's
execution, caching, and provenance. For the shortest example of a step that calls a model, see
[Steps](/fxtr/concepts/workflows-and-steps#steps) in the fxtr concepts.
