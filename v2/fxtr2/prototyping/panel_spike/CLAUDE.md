This is a directory where we are prototyping a panel viewer system.

You can read spec.md in this folder for high-level context about what we are building.

For an overview of the contents of the prototype, see overview.md in this folder.

Whenever you make a substantial change to the codebase organization (e.g. adding a new file, or refactoring the fundamental structure of something), please also modify overview.md so that it is up to date! (You do not need to write a chronological log of everything you changed here, this doc should instead describe the _current_ state of the codebase, for someone coming to it with fresh eyes. You should make sure that the file listing is still accurate, that any new fundamental concepts are briefly mentioned, and that generally if someone was asked to make a change that they could use this file to figure out what to read and what to change.)

If told to create an implementation plan for a goal document, you may want to think through the details first. To avoid cluttering the plan, you should create a new file `{name_of_plan}_scratch.md` adjacent to the original plan doc, and write your scratch thoughts there. Then you can ask clarification questions if you have them, and then finally you can write a consise plan about how to implement the feature at the bottom of the original `{name_of_plan}.md`
