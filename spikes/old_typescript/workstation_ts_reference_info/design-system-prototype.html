Attention as Soft Dictionary Lookup

The attention mechanism can be understood as a differentiable dictionary. Each query vector computes a similarity score against all key vectors, and the resulting weights are used to return a blended value. This framing clarifies why positional encodings are necessary — without them, the dictionary is order-agnostic.

This interpretation was first suggested by Vaswani et al.[1] and later formalized in the kernel attention literature.[4]

Sparse Retrieval Variants

When the attention distribution is sparse — as in top-k attention or entmax — the mechanism behaves more like a hard lookup. This trades off the smoothness of gradients for computational efficiency and interpretability.

score(q, k) = softmax(q · kᵀ / √d_k) · V

The denominator √dk is a temperature parameter that controls the entropy of the attention distribution. Lower temperatures produce sharper distributions, converging toward argmax behavior.[2]

Multi-Head Decomposition

Each head can be seen as a separate dictionary, specialized to different relationship types. Empirically, heads in lower layers tend to capture positional and syntactic patterns, while upper-layer heads capture more semantic relationships.

Pruning experiments suggest that 30–50% of heads can be removed with minimal performance degradation, indicating significant redundancy in standard configurations.[3]
